## 1. Установка

```bash
git checkout -b superbot
# скопировать содержимое папки redesign/ в корень репозитория (с заменой файлов)
node scripts/apply-redesign.mjs --dry     # посмотреть, что изменит
node scripts/apply-redesign.mjs           # применить (идемпотентно)
npm install                               # подтянет sharp
sh scripts/fetch-hero.sh                  # фото персонажа -> public/figma/hero.png
```

Скрипт `apply-redesign.mjs` делает: перекрашивает остальные страницы в палитру макета; подключает `registerBusiness` в `lib/bot.js` (до `session()`); переводит `callQwen` в `lib/qwen.js` на цепочку провайдеров; добавляет секрет вебхука; добавляет `sharp`.

Если `fetch-hero.sh` пишет «не скачалось» — ссылка на ассет Figma временная (живёт около недели). Либо экспортируй слой «image 200» в PNG и положи в `public/figma/hero.png`, либо запроси у меня свежую ссылку и запусти `HERO_URL="..." sh scripts/fetch-hero.sh`. Без картинки всё работает, просто карточка питания без персонажа.

## 2. База данных

Supabase → SQL Editor → выполнить `supabase/business.sql` (таблицы: подключения, настройки, чаты, история, состояние ИИ-провайдеров, очередь задач).

## 3. Переменные окружения (Vercel → Settings → Environment Variables)

| Переменная | Значение |
|---|---|
| `OPENROUTER_API_KEY` | ключ OpenRouter |
| `OPENROUTER_MODEL` | по умолчанию `openrouter/free` (роутер бесплатных моделей) |
| `BAZAAR_API_KEY` | ключ BazaarLink (`sk-bl-…`) |
| `BAZAAR_MODEL` | по умолчанию `auto:free` |
| `BAZAAR_API_URL` | по умолчанию `https://api.bazaarlink.ai/v1/chat/completions` |
| `AI_PROVIDERS` | порядок: `qwen,openrouter,bazaar` (по умолчанию так) |
| `TELEGRAM_WEBHOOK_SECRET` | любая длинная случайная строка |

Про «bazaar»: по описанию это BazaarLink — OpenAI-совместимый шлюз, база `https://api.bazaarlink.ai/v1`, бесплатная модель `auto:free` (по их документации лимит около 10 запросов в минуту и 150 в сутки). Если у тебя другой сервис — поменяй `BAZAAR_API_URL` и `BAZAAR_MODEL`.

**Как работает переключение** (`lib/llm.js`): запрос идёт к первому провайдеру; при 429 (лимит в минуту или суточный), 402 (кончились кредиты), 401/403, 5xx или таймауте провайдер «отдыхает» (минута / до полуночи UTC / час / 30 с — общее состояние в таблице `ai_provider_state`), и берётся следующий. Работает и для чата с ботом (`/ai`), и для автоответов, и для расчёта КБЖУ.

## 4. Вебхук и включение Business в BotFather

```bash
TELEGRAM_BOT_TOKEN=... MINIAPP_URL=https://твой-домен/miniapp/dashboard \
TELEGRAM_WEBHOOK_SECRET=та_же_строка sh scripts/set-webhook.sh
```
Скрипт явно включает Business-апдейты (без `allowed_updates` бот их не получит) и секрет вебхука.

Дальше в Telegram:
1. @BotFather → твой бот → **Bot Settings → Business Mode → включить**.
2. Нужен Telegram Premium. Настройки → **Telegram для бизнеса → Чат-боты** → выбрать бота.
3. Выдать права: отвечать на сообщения; удалять отправленные; удалять любые; управлять историями. После подключения бот пришлёт в личку, какие права получил.

## 5. Как это работает

- **Кто попадает к боту.** Business-режим отдаёт боту только личные чаты аккаунта — группы и каналы Telegram не присылает вообще. Ботов бот отсекает сам (помечает «Игнор», ИИ не тратится). Стикеры, фото без подписи и т.п. тоже не уходят в ИИ; голосовые расшифровываются.
- **Фильтр чатов** (вкладка «Telegram»): *Выбранные* (по умолчанию — безопаснее всего), *Новые* (чаты, где ты ещё не отвечал сам), *Все*. Telegram не сообщает, «старый» ли чат, поэтому «новый» = чат, который бот увидел впервые.
- **Ответ.** Персона (настройки) + база знаний + последние 20 сообщений чата. Если ответа нет в базе или нужно твоё решение (оплата, договорённости, жалоба) — модель отвечает `[HANDOFF]`: собеседнику ничего не уходит, а тебе в личку приходит «нужен ты».
- **Не перебивает тебя:** если ты ответил сам, ИИ молчит в этом чате N часов (настраивается). Серия сообщений подряд = один ответ (пауза перед ответом, по умолчанию 4 с).
- **Вкладка «Telegram»:** статус подключения и права, переключатель автоответа, фильтр чатов, «как отвечать», база знаний, список чатов (статус, «ИИ выкл», «Мут»), шпаргалка команд, состояние нейросетей.

## 6. Команды (пишешь от своего аккаунта в любом подключённом чате)

| Команда | Что делает |
|---|---|
| `.gpt вопрос` | ответ нейросети прямо в чат (или ответом на сообщение) |
| `.a_gpt_off` / `.a_gpt_on` | выключить / включить автоответ в этом чате |
| `.a_mute` | автоудаление сообщений собеседника (вкл/выкл) |
| `.stories` | фото с подписью `.stories` (или ответом на фото) → 9 частей → 9 историй |
| `.circle` | видео с подписью `.circle` (или ответом) → видео-кружок |
| `.save ссылка` | видео из TikTok / Shorts / Reels / VK |

Подтверждения («автоответ выключен» и т.п.) приходят **тебе в личку с ботом**, а не в чат — собеседник их не видит. Сама команда из чата удаляется, если у бота есть право «удалять отправленные».

`.stories`: фото обрезается по центру до 9:16 и режется на 3×3; публикуются с 9-й плитки к 1-й, чтобы в сетке профиля порядок был правильный; истории остаются в профиле (`post_to_chat_page`).

## 7. Воркер для `.circle` и `.save`

Нужны ffmpeg и yt-dlp — на Vercel их не запустить, плюс YouTube/Instagram часто блокируют IP дата-центров. Поэтому бот лишь кладёт задачу в таблицу `jobs`, а небольшой воркер (`worker/`) на VPS её выполняет и отправляет результат от твоего имени.

```bash
# на Ubuntu/Debian VPS, из папки worker/
sudo sh setup.sh        # первый запуск создаст .env — заполни его и запусти ещё раз
journalctl -u biz-worker -f
```
Для Instagram/VK часто нужен файл cookies (`YTDLP_COOKIES` в `.env`). Ограничения Bot API: исходник для `.circle` — до 20 МБ, отправляемый файл — до 50 МБ (при превышении `.save` пережимает).

## 8. Что я не мог проверить — проверь первым делом

Я не мог запустить это против живого Telegram, поэтому на первом прогоне посмотри:
1. После подключения бота пришло сообщение со списком прав (значит `business_connection` доходит).
2. Написать себе с другого аккаунта при фильтре «Все» — бот ответил; в «Выбранные» — молчит, пока чат не отмечен.
3. `.stories` — самая «свежая» часть Bot API (метод `postStory`, загрузка файла внутри вложенного объекта). Если упадёт — в личку придёт текст ошибки Telegram, пришли его мне.
4. Права: без «управлять историями» / «удалять сообщения» соответствующие команды вежливо сообщат, чего не хватает.
