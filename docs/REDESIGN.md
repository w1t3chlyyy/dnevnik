## 2. Шаги

```bash
git checkout -b redesign
# 1) скопировать файлы из архива в корень репозитория (с заменой)
# 2) прогнать кодмод (сначала --dry, он только покажет файлы)
node scripts/apply-redesign.mjs --dry
node scripts/apply-redesign.mjs
# 3) картинка персонажа (нужен Figma personal access token)
FIGMA_TOKEN=figd_xxx node scripts/fetch-figma-assets.mjs     # -> public/figma/hero.png
npm run dev      # проверить в браузере в режиме телефона (390×844)
git add -A && git commit -m "redesign: dashboard + shared style" && git push -u origin redesign
```

Без `public/figma/hero.png` карточка питания просто покажется без персонажа (картинка скрывается по `onError`) — ничего не ломается.

Telegram: при открытии вне Telegram `apiGet` шлёт пустой `initData` и API отвечает 401 — дашборд покажет нули. Проверять нужно через бота (кнопка «Открыть панель») либо на Vercel preview.

## 3. Как устроена вёрстка «1 в 1»

- Рабочая ширина контента во фрейме — 687px (отступ 107px от краёв 900px). Все размеры и координаты из Figma переводятся функцией `u(n)` (`lib/fx.js`) в `cqw` — то есть масштабируются от ширины карточки. Элементы внутри карточек стоят абсолютно в **тех же координатах, что в Figma** — сверять с макетом можно по `data-node-id`-координатам.
- Карточки — SVG-контуры из Figma с вырезами (Rectangle 411 / 417 / 419), `components/ShapeCard.js`. Кнопки «Список целей», «Ежедневные», «Питание» лежат внутри вырезов, как в макете.
- Фон — те же два пути с blur 150 и 200 (`AmbientBackground`), прижаты к низу экрана.
- Шрифты: Unbounded (Light/Regular/Medium) и Montserrat. В Google Fonts импорт добавлен вес Unbounded 300.
- Минимальный размер шрифта ограничен (`fs(n, min)`): при честном масштабировании на 390px подписи 12–20px макета давали бы 5–9px, что нечитаемо. Все заголовки и числа масштабируются строго, подписи — с «полом» 8–11px.

## 5. Остальные страницы

Макетов остальных экранов нет, поэтому они переведены на тот же стиль через токены: карточки `#171717` с крупным скруглением, акцентные панели `#2F6BFF`, палитра графиков — оттенки синего (`#2F6BFF`, `#D6E2FF`, `#1C4099`). Кодмод заменяет старые hex-цвета (фиолетовый/бирюзовый/оранжевый…) и убирает цели дня из «Списка целей».

Если нужна точная вёрстка конкретных экранов — пришли фреймы, сделаю так же, как дашборд.
